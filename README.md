# ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/everluma/monisha-portfolio.git
```

Go to project folder:

```bash
cd monisha-portfolio
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```
